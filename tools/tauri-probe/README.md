# Проверка оболочки Ark (этап 0, T-06)

Маленькая программа на том же стеке, что будет у Ark: Tauri 2 + Svelte 5 + Three.js + mesh-kit. Это не
макет интерфейса, а проверка: работает ли просмотр 3D и обработка сетки во встроенном браузере каждой
системы (WebView2 на Windows, WebKit на Mac, WebKitGTK на Linux).

Скрипт сам ставит Rust и Node, собирает программу и установщик, открывает окно на минуту и упаковывает
отчёт. В окне по очереди идут проверки:

1. Rust и страница видят друг друга.
2. Есть WebGL 2, какая видеокарта рисует.
3. Частота кадров без нагрузки — от неё считаем остальное.
4. Модель на 1 млн и на 250 тыс. треугольников открывается тем же путём, что настоящий файл, и
   вращается. Меряется каждый кадр.
5. Пока модель вращается, в фоновом потоке mesh-kit чинит её (две дыры), ставит на стол и пишет STL.
   Проверяем, что вращение при этом не тормозит.
6. Rust записывает STL в папку с пробелами и кириллицей: `Ковчег тест/модель для печати.stl`.
7. Видеокарта «теряет» контекст и получает его обратно, модель рисуется снова.

## Когда запускать
**На ПК с RTX — только после того, как закончится полный прогон бенча.** Там сейчас меряется время
на процессоре, и сборка Rust его испортит. На Mac можно запускать сразу.

Запускайте за монитором самого компьютера. У удалённого рабочего стола экран на 32 Гц, поэтому и частота
кадров там будет около 32, какой бы быстрой ни была видеокарта. Остальные шаги это не портит.

## Как запустить
- **Windows 11:** двойной щелчок по `START.cmd`. В первый раз скрипт поставит Microsoft C++ Build
  Tools — без них Rust на Windows не собирает программы. Windows спросит разрешение администратора,
  установка займёт 10–20 минут и около 5 ГБ.
- **Mac (Apple Silicon):** `START-MAC.sh` из `ark-mac.zip` запускает эту проверку и бенч подряд, см.
  README бенча. Окно откроется и закроется само. Отдельно: `sh run.sh` из этой папки в Терминале.
- **Linux (Ubuntu 24.04):**
  `sudo apt install libwebkit2gtk-4.1-dev build-essential curl file libxdo-dev libssl-dev librsvg2-dev`,
  потом `sh run.sh`.

Первая сборка на 12 потоках заняла 3 минуты, на слабом ПК будет дольше. Потом откроется окно: подождите, пока справа не появится «Отчёт
сохранён» (около минуты), и закройте окно. Окно не сворачивайте, пока идут проверки: свёрнутому окну
система не даёт рисовать кадры. Можно покрутить модель мышью и перетащить в окно свою модель из
бенча (`N:\bench\results\…\outputs\*.glb`) — посмотреть, как она открывается.

**Пришлите `results\<дата>-probe-report.zip`.** В нём отчёт программы, журнал сборки и размеры
установщика.

## Что ставится и как убрать
- В папку `.work` рядом с этим файлом: Rust 1.99.1 (около 1,5 ГБ), Node 24 и Python для скрипта.
  В `src-tauri\target` — сборка (около 2 ГБ). Удалите обе папки, и ничего не останется.
- Только Windows: C++ Build Tools ставятся в систему. Удаляются через «Установка и удаление
  программ» → «Visual Studio Build Tools». Сборщик установщика Tauri скачивает NSIS в
  `%LOCALAPPDATA%\tauri`.

## Безопасность
Сборка скачивает около 400 пакетов Rust с crates.io и пакеты npm. Версии закреплены
(`Cargo.lock`, `package-lock.json`), Rust и Node сверяются по sha256. Но код этих пакетов исполняется
при сборке с правами вашей учётной записи. Совет тот же, что для бенча: отдельная учётная запись без
открытых паролей и кошельков.

## Для разработки
- `npm run dev` — страница в обычном браузере: проверки без Rust (шаги Tauri пропускаются).
- `npm run check` — проверка типов.
